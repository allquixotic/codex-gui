# Contributing

This is an independent community GUI project. Contributions are informal:
open an issue with what you expected and what happened, or send a focused pull
request. Screenshots, reproduction steps, and your platform help with UI bugs.

Please preserve GUI.md, existing features, and the latest-stable upstream policy.
Include relevant verification and a regression test when fixing behavior.
Follow AGENTS.md for maintenance and the prohibition on GUI testing on Sean's Mac.

Contributions are provided under Apache-2.0, the project's license. There is
no separate CLA. We are not directly attached to the OpenAI Codex CLI project.
